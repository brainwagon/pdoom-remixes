How this works. A GitHub Action runs once a day, searches YouTube and SoundCloud (and Suno when a token is configured), classifies each hit as a remix, cover, version or merely a new music video for existing audio, and appends the genuine renditions here. The dataset is append-only: once a video is listed it is never deleted, even if it disappears from the search results or is pulled from the platform. The underlying data is committed to the repository and mirrored at videos.json.
